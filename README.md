# VEX Robot Corp - Marketing Website

This is a professional, modern website designed to market VEX Robots for Startup Africa. It's a fully responsive, mobile-friendly platform that showcases robotics products and connects with potential customers.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Product Showcase**: Displays VEX IQ, VEX V5, and VEX EDR products
- **Contact Form**: Easy inquiry form for potential customers
- **Modern UI**: Clean, professional design with smooth animations
- **Africa-Focused**: Tailored content for the African market and Startup Africa partnership

## Products Featured

1. **VEX IQ** - Perfect for elementary and middle school students
2. **VEX V5** - Advanced platform for high school and university students
3. **VEX EDR** - Educational robotics kit with comprehensive curriculum

## Getting Started

Simply open `index.html` in any modern web browser to view the website.
